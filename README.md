##　作るきっかけ
この商品ほしいけどもう少し安くなればな。。。と思った人は多いはず、なら安くなったら教えてくれるアプリを作ちゃえばいい、　これがきっかけで作ることにしました。

##　このサイトについて
このサイトでは　AMAZONのURLを登録するとその値段が変化するとメッセージが飛ぶ仕組み（安くなったのか、高くなったのかわかります）です。

## 面倒なパスワードとemailの打ち込む機会を減らす。
利用しようと開くたびに毎回書いてからログインではめんどくさい。なので、Cookieに情報を組み込み、ユーザーが素早く利用しやすいようにしました。

# セキュリティに関して
大事な情報（JWT）はCookieに組み込みhttponlyにしているためXSSの対策。　バックエンド側でアクセスを制限CORS対策。　JWTを使うことでデータの改ざんを防げる。
